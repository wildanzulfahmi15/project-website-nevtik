A.konfigurasi server (seperti dns,dhcp,http)

Mari Kita Lihat Penjelasannya!!

Konfigurasi server adalah proses pengaturan dan penyesuaian
sistem server agar dapat menjalankan layanan tertentu sesuai
kebutuhan jaringan. Beberapa layanan utama yang sering
dikonfigurasi pada server meliputi DNS, DHCP, dan HTTP.

B. Penguasaan tools jaringan
dan alat (Cisco,Mikrotik.)

Mari Kita Lihat Penjelasannya!!

MikroTik adalah perusahaan asal Latvia yang memproduksi perangkat jaringan,
terutama router dan wireless. Produk utamanya adalah RouterOS, sebuah sistem
operasi berbasis Linux yang digunakan pada router MikroTik.
Cisco adalah perusahaan teknologi asal Amerika Serikat yang terkenal dalam
bidang jaringan komputer dan telekomunikasi. Cisco memproduksi berbagai
perangkat jaringan seperti router, switch, firewall, dan access point yang
digunakan dalam skala kecil hingga enterprise (perusahaan besar).

C. deploy web dalam local

Deploy web dalam lokal berarti menjalankan atau
menyebarkan aplikasi web di lingkungan lokal
(komputer sendiri) tanpa perlu mengunggahnya ke
server online. Ini sering dilakukan untuk
pengembangan, pengujian, atau demonstrasi sebelum
web dipublikasikan ke internet.
